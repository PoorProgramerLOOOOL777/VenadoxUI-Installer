Apariencia para Discord

Bienvenido a VenadoxUI 🖌

Este instalador es para la apariencia de Discord.

Pasos para instalar la extensión de Discord

  1. Instálala desde la página oficial, que es esta.
  2. Ten WinRAR instalado para descomprimir el/los archivos.
  3. Haz clic derecho sobre el archivo descomprimido y elige «Instalar».
  4. Ve a la configuración de Discord y entra donde diga VenadoxUI.
  5. ¡Enhorabuena! Ya instalaste VenadoxUI 🖌 en tu Discord.
